# 商店展示用图片

本目录的图片由仓库根目录的 `screenshots.json` 声明，供插件市场详情页展示。

- `screenshot-console-light.png` / `screenshot-console-dark.png`：本地控制台
  `概览 · 端口与操作` 面板的实机截图，浅色与深色两套主题（2026-10-30）。
  截图里能看到端口与进程监控（控制台、DSH 宿主、OneBot 反向 WS、Waylay 等）。
- `icon-256.png`：256×256 方形图标，供市场卡片用作 `icon:` 字段。

## 关于版本与隐私

- 这批截图来自较早的控制台界面（当时控制台端口是 8883，并带有
  GPT-SoVITS / NapCat WebUI 等旁路项）。当前 v0.1.0 的控制台是 8880，
  顶栏会显示版本戳，界面布局已有调整。截图只用来展示控制台的监控面板，
  不代表当前版本的精确外观。
- 为保护隐私，上传前对原图做了**裁切**：去掉右侧「运行快照」栏、
  底部「路径配置」以及操作区含本机绝对路径的日志行。裁切后的两张图
  不含 `C:\Users\<user>\...` 之类的绝对路径、QQ 号、token、API key 或聊天内容。
  原图未提交、未上传。
- 用户 QQ 聊天界面的截图因含私人对话与头像，未选入展示图。
