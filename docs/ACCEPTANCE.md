# 真机验收清单

> 为什么是"真机"：这两天已经证明两次——**代码里写着，不等于真机上能用**
> （`get_msg` 有内核调用却恒空、`get_forward_msg` 有 handler 却返回空数组）。
> 所以这份清单只做一件事：**每条都能给出"成/败 + 证据"**，而不是"我看了一下觉得没问题"。

## 先跑自动项：`!qa`

私聊她发 `!qa`（管理员指令），一次验完**能自动验的那一半**：

| 自动项 | 判据 |
|---|---|
| OneBot 通道 | socket 在 |
| 模型 | provider/model 非空 |
| 图片代理 | `127.0.0.1:6701` 在听（否则报 `ONEBOT_WS_PORT` 提示）|
| 内核取历史 | `get_friend_msg_history` 真能取到（引用/聊天记录的命根子）|
| 会话映射 | 在用几条 / 侧栏挂几条 / 旧几条 |

⚠️ `!qa` **验不了她答得对不对** —— 那必须人看。所以下面这份清单仍然要过一遍。

## 用法（两条命令，不需要别人帮忙）

1. 做完一条或多条，跑：

```bash
node tools/qa-snapshot.mjs 10     # 最近 10 分钟
```

2. 把输出的**整段**贴回来。里面已经分好四块：入站、各阶段成功/失败、桥日志细节、Waylay 内核调用。

判定原则（三条，按顺序）：

| 判据 | 含义 |
|---|---|
| `trace` 里出现对应 stage 且 `ok:true` | 这条链路走到了该走的地方 |
| 桥日志有对应细节行（如 `quote resolve: … got=msg`） | 数据真的取到了，不是空跑 |
| 她**回复的内容**对得上 | 这才是用户能感知的部分 |

⚠️ 只有第 3 条为真才算通过。前两条全绿但她答错，仍然算失败——那说明数据进了模型但没被用上。

## 一、必测（先说这些，因为今天刚改过）

### 1. 纯文字

- **发**：一句普通的话，比如「今天好累」
- **预期**：她按「一条一句」回，可能拆成多条
- **判据**：trace `reply ok`；她的话不与前文串味

### 2. 引用文字

- **发**：引用她或你的**一句话**，再写一句（如「这个呢」）
- **预期**：她答的是被引用的那句，不是装看不见
- **判据**：桥日志 `quote resolve: … got=msg segments≥1 types=["text"]`

### 3. 引用图片 ⭐ 今天刚修

- **发**：引用一条**带图**的消息
- **预期**：她能说出图里是什么
- **判据**：`quote resolve … types=["text","image"]` 且**没有** `quote image download failed`
- **失败先看**：`HTTP 400 invalid rkey` ⇒ 图片代理没生效（`ONEBOT_WS_PORT` 是否为 6701）；`404` ⇒ QQ 本地没有那份缓存

### 4. 聊天记录（合并转发）⭐ 今天刚修

- **发**：选中几条消息 → 合并转发给她
- **预期**：她读得到里面的内容（能接上其中某句）
- **判据**：trace `forward ok`；桥日志有转发节点数；Waylay `[forward] getMultiMsg(...) → keys=… count=N`
- **失败先看**：`forward 内容为空或无法解析` + `drop 转发卡片展开后没有可读内容` ⇒ 展开失败，
  看 `[forward]` 那几行是哪个实参形态报错

### 5. 嵌套聊天记录 ⭐ 今天刚修

- **发**：聊天记录里**再套**一条聊天记录（QQ 里可以做到：转发一条已经是聊天记录的消息）
- **预期**：两层都能读到，或者至少外层能读到、内层标明"这里套了一条"
- **判据**：`[forward]` 日志出现**两次** `count≥1`（外层 + 内层）
- **已知上限**：最多展开 2 层，再深就只给外层（防自引用死循环）

## 二、常规项

### 6. 图片（非引用）

- **发**：一张图，问「这是啥」
- **预期**：她描述得出来
- **判据**：trace `vision`/`card` 有记录；她的话里有画面细节

### 7. 语音

- **发**：一条语音（3–5 秒）
- **预期**：她按内容回
- **判据**：trace `record ok`；没有 `听不到内容` 的兜底话术
- **已知边界**：云端 STT 没配 Key 时，她会如实说听不到

### 8. 表情包

- **发**：任一消息，等她回
- **预期**：**4–6 轮**出现一次表情，不是每句都有
- **判据**：trace `sticker ok`；连发两条都带图 = 频率坏了

### 9. 群聊 @ 她

- **发**：在群里 @ 她 + 一句话
- **预期**：群里回，且不刷屏
- **判据**：trace `inbound`（`atMe:true`）→ `reply ok`

### 10. 主动开口

- **等**：什么都不发，等 25 分钟以上（或触发旁白）
- **预期**：她可能在没消息时开口，或回 `[不说]`
- **判据**：trace 里有主动通道事件；她说的话**不是**"关心你"式的定时问候

## 三、已知不可用（别当 bug 报）

| 项 | 状态 | 原因 |
|---|---|---|
| 发说说（QQ 空间） | ❌ 不可用 | Waylay 没实现 `send_qzone_msg`（retcode 1404），已做能力探测并停用这条由头 |
| 群文件链接 / 群精华 / 群荣誉 | ❌ 空壳 | Waylay 这几个 handler 直接返回空，没有内核调用 |
| 引用**很早**的消息（> 最新 50 条） | ⚠️ 部分 | `get_msg` 兜底只扫最近 50 条；更早的要再加"按 seq 回溯" |
| 引用里 QQ 本地没有缓存的图 | ⚠️ 部分 | 代理取不到，会如实说"下载失败"，不编内容 |
