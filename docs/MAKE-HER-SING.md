# 怎么让她唱一首歌

> 写于 2026-11-04。起因：念唱版本被评价为「很正常的助手腔，跟唱歌远多了」——
> 这个判断是对的，而且原因不在参数。

## 一句话说清为什么念唱不像歌

**唱 = 每个音节落在具体的音高上、时长由音符决定。**
edge-tts 只能给整段文本一个 `pitch`（整体升降），音节之间的音程关系它管不了。

所以：
- 我们现在的 `!唱` = **有起伏地念**（pitch 收窄后连"怪"都没了，只剩"助手腔"）
- 真正的唱 = **必须先有旋律**（MIDI/谱面），再由模型把歌词铺到音符上

B 站那波「AI 孙燕姿」不是靠调 TTS 参数做出来的，是靠 **SVC（歌声转换）** 或 **SVS（歌声合成）**。

## 三条路，按"你今天就能出成品"排序

### 路线 1：ACE Studio（推荐，最快出成品）

> 官网 `acestudio.ai`，本机可访问（302）。140+ 声线、8 语言、支持**声音克隆**。

B 站教程里的标准流程（[flowpixai 的翻唱教程](https://flowpixai.com/tutorials/ai-song-cover-tutorial.html) 讲得最细）：

1. **要有伴奏**（可选）：用 **UVR**（Ultimate Vocal Remover，免费开源）把原曲拆成人声 + 伴奏
2. 把伴奏拖进 ACE Studio
3. **输入歌词**，按段落分行
4. **画旋律线**（或用 MIDI 导入）——「每个字对应一个音高」，这一步是"唱"和"念"的分水岭
5. 选一个 AI 声线（想是"她"的声音就用**声音克隆**：上传几秒她的语音样本训练）
6. **调参数**（教程原话）：
   - 默认参数出的翻唱「**AI 味太重**」，朋友一听就说 AI
   - **气声加到 20–30%** 会明显更自然
   - 加一点**颤音**和**力度起伏**
7. 导出 mp3

### 路线 2：网易天音（国内直连，网页版）

`tianyin.music.163.com` 本机返回 200，可直接用。适合"不想装软件、先试一下"。
能力弱于 ACE Studio（尤其声音克隆），但零安装。

### 路线 3：本地开源（DiffSinger + OpenUtau）

- **能力最强、完全免费**，但要谱面（`.ustx`）。
- **更正（2026-11-04 晚）**：我一开始写"本机装不上"，那个判断是**错的**，错在两处：
  1. 只测了 `github.com`（000）就断言"不通"。实际 **`gh-proxy.com` 通（200）、`codeload.github.com` 通（301）、`gitee.com` 通（200）**，
     经 gh-proxy 能正常调 GitHub API 与下 release（实测 **355 KB/s**，`OpenUtau-win-x64.zip` 160.7MB、最新 0.1.576）。
  2. 把"DiffSinger **训练**要 Python 3.9"和"**推理**"混为一谈。**OpenUtau 是 C#/.NET 应用**，
     推理走 ONNX，**完全不依赖 Python** —— 系统是 3.13 也不影响。
- **真正的卡点不是网络，是这两条**：
  - **OpenUtau 没有 CLI**（`Program.cs` 里 `args` 只透传给 Avalonia 启动器），
    ⇒ **渲染必须在 GUI 里点**，脚本没法"一键出歌"。
  - **要先有声库**（voicebank）：经典 UTAU 声库或 DiffSinger 声库（`.dsconfig` + ONNX），几百 MB，得另找。
- 能自动化的那一步：`.ustx` 是 **YAML**（`YamlDotNet` 序列化 `UProject`），
  字段已知（`tempos[]` / `timeSignatures[]` / `tracks[]` / `parts[].notes[]`，
  音符是 `position` / `duration` / `tone` / `lyric`，另有 `pitch` 与 **`vibrato`**）。
  ⇒ 可以**脚本生成工程**（把"输歌词 + 画旋律"这步省掉），剩下的"打开 → 点渲染 → 导出"必须人工。
  （`vibrato` 字段值得用：ACE 教程里"加颤音能大幅减少机械感"是同一条经验。）
- 产物也是 mp3，最后还是丢进同一个曲库目录。

## 做完之后：放进曲库，她就会"唱"了

```
<dataRoot>/qq-voices/songs/     ← 把她唱的歌放这里（mp3/wav/m4a/ogg/flac）
```

然后在 QQ 里：

| 你说 | 她做什么 |
|---|---|
| `!唱 列表` | 列出曲库里有哪些歌（没有歌时会把目录路径告诉你） |
| `!唱 小兔子乖乖` | **原样播放** `小兔子乖乖.mp3`（真唱，不合成） |
| `!唱 小兔子` | 模糊匹配也能命中（精确优先，其次包含） |
| `!唱 今天天气不错` | 曲库没有 ⇒ 退回**念唱**，并明确告诉你"这是念的不是唱的" |

匹配规则：精确优先 → 包含（双向）→ 忽略大小写与扩展名。

## 版权与分寸（别忽略）

- **翻唱别人的歌**：音色是她的、旋律是别人的 ⇒ 自己听没问题，**公开发布要慎重**（伴奏/曲谱都有版权）。
- **声音克隆**：只克隆**你自己的声音**或已获授权的音色。克隆真人（尤其公众人物）并公开发布，
  在国内平台已被明确治理。
- 最安全的一类：**自己写的词曲**（哪怕很简单），用 ACE Studio 编个伴奏，让她唱。

## 一句实话

`!唱` 的念唱版不是"唱得不好"，是**路线不同**：它是"她在念叨"，落在人设里其实也能用
（比如"她哼着说"）。要"她真的唱歌"，就必须走上面三条之一——**没有第四条**。

## 附：两条常见误解（2026-11-04 实测）

### 「用 DeepSeek 的声库不就行了」——不存在这个声库

- DeepSeek 网页/App 的朗读（贝壳/白浪/海星/暗潮，英文 Mira/Echo/Stella/Tide）是**前端功能**，
  官方**从未开放 API，也没有发布任何声库权重**。
- 我们 `qq_chat/tts-server` 里的「贝壳」是**映射**到微软 `zh-CN-XiaoyiNeural`（同一代技术的等价物），
  不是 DeepSeek 的原声。
- 想拿到那个确切声音，只有「录下来 + 克隆」这一条路 —— 属于逆向使用，
  且克隆出的音色权利归属不明，**不建议**。

### 「随便找个声库让她唱」——多数声库禁止改名

| 声库 | 条款要点 |
|---|---|
| **绮萱**（Qixuan, DiffSinger） | **禁止「使用其他名称对合成人声署名」**；公开发布须标注「绮萱」+「DiffSinger」+「AI 合成」；禁止逆向/微调权重 |
| **Defoko**（唄音ウタ, UTAU 预装） | 商用与衍生角色**需许可**；R-18 禁止；声音本身是 AquesTalk TTS，机械感强 |

⇒ 要让「她」以自己的名字唱歌，合规路只有三条：
1. **自己的声音**训练一个声库（工程量大，但无授权问题）；
2. **ACE Studio 声音克隆**（克隆现成的「她」的合成音，边界仍需自己判断）；
3. **接受"她借用某声库唱歌"**，并如实署名该声库 —— 不能声称那是她自己的声音。

## 补充（2026-11-04 晚）：有人把整条翻唱流水线做成了 DSH 插件

比"手动装 OpenUtau + 找声库"省事得多，**已核过代码与依赖**：

### 两个仓库

| 仓库 | 定位 | 关键点 |
|---|---|---|
| [`CixiSVesper/dsh-soundtry`](https://github.com/CixiSVesper/dsh-soundtry) | **音频理解**（6 工具）：转写 whisper-medium、节奏、旋律、和弦、结构、**人声分离** | 分离用 **UVR MDX-Net + onnxruntime**（**不需要 torch**）；要 Python 3.10–3.12 |
| [`InariNGT-Ofiicial/dsh-cover-pipeline`](https://github.com/InariNGT-Ofiicial/dsh-cover-pipeline) | **AI 翻唱流水线**（9 工具）：`分离 → 换声 → 移调 → 混音 → 验收` | JS 零运行时依赖；重活交给 **MSST**（分离）+ **DDSP-SVC**（换声） |

### 为什么它比 OpenUtau 路线更适合"唱歌"

- **不需要谱面**：直接拿现成的歌，把人声换成目标音色（SVC 思路）
- **有现成音色**：8 人音色包（演示用「祥子」267MB）
- **整合包自带 `env/python.exe`** ⇒ 不吃系统 Python 3.13 的限制

### 落地只缺三个网盘包（约 5GB，来源见 `materials/README.md`）

| # | 材料 | 码 | 落位 |
|---|---|---|---|
| 1 | MSST-GUI 人声分离整合包 | `u3r2` | `<根>/01_人声分离_MSST-GUI` |
| 2 | DDSP-SVC 6.2 整合包 | `j44k` | `<根>/02_模型推理_DDSP-SVC-6.2/DDSP-barbara-6.2` |
| 3 | 8 人音色模型包 | `2aj9` | `<根>/03_音色模型_MYGO-AveMujica` |

默认根目录 `D:/AI-Song`（插件按 `01_/02_/03_` 前缀自动发现）。

### 本机自检结果（2026-11-04）

```
✅ 随包流水线脚本 8/8（runtime/ 齐全）
❌ MSST / DDSP 目录与各自 python、Kim/karaoke 权重、ContentVec、HiFiGAN、音色「祥子」
```
⇒ 插件本体没问题，**全部缺口都在那三个网盘包里**。
