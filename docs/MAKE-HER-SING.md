# 怎么让她唱一首歌

> 写于 2026-11-04。起因：念唱版本被评价为「很正常的助手腔，跟唱歌远多了」——
> 这个判断是对的，而且原因不在参数。

## 一句话说清为什么念唱不像歌

**唱 = 每个音节落在具体的音高上、时长由音符决定。**
edge-tts 只能给整段文本一个 `pitch`（整体升降），音节之间的音程关系它管不了。

所以：
- 我们现在的 `!唱` = **有起伏地念**（pitch 收窄后连"怪"都没了，只剩"助手腔"）
- 真正的唱 = **必须先有旋律**（MIDI/谱面），再由模型把歌词铺到音符上

B 站那波「AI 孙燕姿」不是靠调 TTS 参数做出来的，是靠 **SVC（歌声转换）** 或 **SVS（歌声合成）**。

## 三条路，按"你今天就能出成品"排序

### 路线 1：ACE Studio（推荐，最快出成品）

> 官网 `acestudio.ai`，本机可访问（302）。140+ 声线、8 语言、支持**声音克隆**。

B 站教程里的标准流程（[flowpixai 的翻唱教程](https://flowpixai.com/tutorials/ai-song-cover-tutorial.html) 讲得最细）：

1. **要有伴奏**（可选）：用 **UVR**（Ultimate Vocal Remover，免费开源）把原曲拆成人声 + 伴奏
2. 把伴奏拖进 ACE Studio
3. **输入歌词**，按段落分行
4. **画旋律线**（或用 MIDI 导入）——「每个字对应一个音高」，这一步是"唱"和"念"的分水岭
5. 选一个 AI 声线（想是"她"的声音就用**声音克隆**：上传几秒她的语音样本训练）
6. **调参数**（教程原话）：
   - 默认参数出的翻唱「**AI 味太重**」，朋友一听就说 AI
   - **气声加到 20–30%** 会明显更自然
   - 加一点**颤音**和**力度起伏**
7. 导出 mp3

### 路线 2：网易天音（国内直连，网页版）

`tianyin.music.163.com` 本机返回 200，可直接用。适合"不想装软件、先试一下"。
能力弱于 ACE Studio（尤其声音克隆），但零安装。

### 路线 3：本地开源（DiffSinger + OpenUtau）

- **能力最强、完全免费**，但要谱面（`.ustx`），且**本机装不上**：
  - `github.com` 与 `huggingface.co` 都返回 **000**（不通），只有 modelscope 通
  - 系统 Python 是 **3.13**，而这些项目的依赖大多要 3.9/3.10
- 想走这条：先从网盘/镜像拿整合包（B 站教程区常有人放），再准备一首歌的谱面。
- 它的产物也是 mp3，最后还是丢进同一个曲库目录。

## 做完之后：放进曲库，她就会"唱"了

```
<dataRoot>/qq-voices/songs/     ← 把她唱的歌放这里（mp3/wav/m4a/ogg/flac）
```

然后在 QQ 里：

| 你说 | 她做什么 |
|---|---|
| `!唱 列表` | 列出曲库里有哪些歌（没有歌时会把目录路径告诉你） |
| `!唱 小兔子乖乖` | **原样播放** `小兔子乖乖.mp3`（真唱，不合成） |
| `!唱 小兔子` | 模糊匹配也能命中（精确优先，其次包含） |
| `!唱 今天天气不错` | 曲库没有 ⇒ 退回**念唱**，并明确告诉你"这是念的不是唱的" |

匹配规则：精确优先 → 包含（双向）→ 忽略大小写与扩展名。

## 版权与分寸（别忽略）

- **翻唱别人的歌**：音色是她的、旋律是别人的 ⇒ 自己听没问题，**公开发布要慎重**（伴奏/曲谱都有版权）。
- **声音克隆**：只克隆**你自己的声音**或已获授权的音色。克隆真人（尤其公众人物）并公开发布，
  在国内平台已被明确治理。
- 最安全的一类：**自己写的词曲**（哪怕很简单），用 ACE Studio 编个伴奏，让她唱。

## 一句实话

`!唱` 的念唱版不是"唱得不好"，是**路线不同**：它是"她在念叨"，落在人设里其实也能用
（比如"她哼着说"）。要"她真的唱歌"，就必须走上面三条之一——**没有第四条**。
